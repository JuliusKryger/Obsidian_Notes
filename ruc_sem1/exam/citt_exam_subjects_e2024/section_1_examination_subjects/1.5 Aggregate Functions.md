#### **What are Aggregate Functions?**

Aggregate functions in SQL perform calculations on a set of values and return a single summary value. They are often used in combination with the `GROUP BY` clause to group rows sharing a common attribute and perform calculations for each group.

---

### Built-in Aggregate Functions:

1. **COUNT()**:
    
    - Returns the number of rows that match a specified condition.
        
    - **Syntax:**
        
        ```
        SELECT COUNT(column_name)
        FROM table_name
        WHERE condition;
        ```
        
    - **Example:** Count the number of students in a course.
        
        ```
        SELECT COUNT(ROLL_NO) AS student_count
        FROM ENROLLMENT
        WHERE COURSE_ID = 101;
        ```
        
2. **SUM()**:
    
    - Calculates the total sum of a numeric column.
        
    - **Syntax:**
        
        ```
        SELECT SUM(column_name)
        FROM table_name
        WHERE condition;
        ```
        
    - **Example:** Calculate total fees collected from students.
        
        ```
        SELECT SUM(FEE) AS total_fees
        FROM PAYMENT;
        ```
        
3. **AVG()**:
    
    - Calculates the average value of a numeric column.
        
    - **Syntax:**
        
        ```
        SELECT AVG(column_name)
        FROM table_name
        WHERE condition;
        ```
        
    - **Example:** Find the average age of students.
        
        ```
        SELECT AVG(AGE) AS average_age
        FROM STUDENT;
        ```
        
4. **MAX()**:
    
    - Returns the maximum value in a column.
        
    - **Syntax:**
        
        ```
        SELECT MAX(column_name)
        FROM table_name
        WHERE condition;
        ```
        
    - **Example:** Find the highest salary among employees.
        
        ```
        SELECT MAX(SALARY) AS highest_salary
        FROM EMPLOYEE;
        ```
        
5. **MIN()**:
    
    - Returns the minimum value in a column.
        
    - **Syntax:**
        
        ```
        SELECT MIN(column_name)
        FROM table_name
        WHERE condition;
        ```
        
    - **Example:** Find the lowest grade in a class.
        
        ```
        SELECT MIN(GRADE) AS lowest_grade
        FROM GRADES;
        ```

### Grouping:

The `GROUP BY` clause is used to arrange identical data into groups. It works with aggregate functions to perform calculations for each group.

#### **Syntax:**

```
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;
```

#### **Example:** Group students by course and count them.

```
SELECT COURSE_ID, COUNT(ROLL_NO) AS student_count
FROM ENROLLMENT
GROUP BY COURSE_ID;
```

---

### Conditions that Apply to Groups:

The `HAVING` clause is used to filter groups based on aggregate function results. It is similar to `WHERE`, but `HAVING` applies to grouped data.

#### **Syntax:**

```
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;
```

#### **Example:** Retrieve courses with more than 10 students.

```
SELECT COURSE_ID, COUNT(ROLL_NO) AS student_count
FROM ENROLLMENT
GROUP BY COURSE_ID
HAVING COUNT(ROLL_NO) > 10;
```

---

### Bullet Points:

#### Built-in Aggregate Functions:

- `COUNT()`: Counts rows.
    
- `SUM()`: Calculates the total.
    
- `AVG()`: Finds the average.
    
- `MAX()`: Retrieves the maximum value.
    
- `MIN()`: Retrieves the minimum value.
    

#### Grouping:

- `GROUP BY`: Organizes data into groups for calculations.
    

#### Filtering Groups:

- `HAVING`: Applies conditions to grouped results (used with `GROUP BY`).
