### Reading Paper:

#### **What are SQL Functions and Procedures?**

SQL functions and procedures are reusable blocks of code that can be executed on the database server to perform specific tasks. They help encapsulate logic, improve code reusability, and optimize database operations by reducing client-server interactions.

---

### SQL Functions:

#### **Purpose:**

- Perform calculations and operations on data.
    
- Return a single value or result set.
    

#### **Types of Functions:**

1. **Built-in Functions:**
    
    - **Aggregate Functions**: `SUM()`, `AVG()`, `COUNT()`, `MAX()`, `MIN()`.
        
    - **String Functions**: `CONCAT()`, `SUBSTRING()`, `LENGTH()`.
        
    - **Date/Time Functions**: `NOW()`, `CURDATE()`, `DATEDIFF()`.
        
    - **Numeric Functions**: `ROUND()`, `CEIL()`, `FLOOR()`.
        
2. **User-Defined Functions (UDFs):**
    
    - Created by users to perform specific tasks.
        
    - **Syntax:**
        
        ```
        CREATE FUNCTION function_name (parameters)
        RETURNS data_type
        BEGIN
          -- Function logic
          RETURN value;
        END;
        ```
        
    - **Example:**
        
        ```
        CREATE FUNCTION GetFullName(firstName VARCHAR(50), lastName VARCHAR(50))
        RETURNS VARCHAR(100)
        BEGIN
          RETURN CONCAT(firstName, ' ', lastName);
        END;
        ```
        
    - **Invocation:**
        
        ```
        SELECT GetFullName('John', 'Doe');
        ```
        

---

### SQL Procedures:

#### **Purpose:**

- Encapsulate a sequence of SQL statements to perform a task.
    
- Improve performance by reducing the number of client-server interactions.
    

#### **Syntax:**

```
CREATE PROCEDURE procedure_name (parameters)
BEGIN
  -- Procedure logic
END;
```

#### **Example:**

Create a procedure to update student grades.

```
CREATE PROCEDURE UpdateGrade (IN studentID INT, IN newGrade INT)
BEGIN
  UPDATE GRADES
  SET grade = newGrade
  WHERE student_id = studentID;
END;
```

#### **Invocation:**

- **Using** `**CALL**`**:**
    
    ```
    CALL UpdateGrade(101, 85);
    ```
    

#### **Differences Between Functions and Procedures:**

- **Functions**: Return a value and are typically used within SQL statements.
    
- **Procedures**: Perform a task and do not necessarily return a value.

### Language Constructs:

#### **Control Statements:**

1. **Conditional Statements:**
    
    - `IF`, `CASE` for decision-making.
        
    - Example:
        
        ```
        IF newGrade > 90 THEN
          SET performance = 'Excellent';
        ELSE
          SET performance = 'Average';
        END IF;
        ```
        
2. **Loops:**
    
    - Repeat actions until a condition is met.
        
    - Example:
        
        ```
        WHILE counter < 10 DO
          SET counter = counter + 1;
        END WHILE;
        ```
        
3. **Cursors:**
    
    - Allow row-by-row processing of query results.
        
    - Example:
        
        ```
        DECLARE cursor_name CURSOR FOR SELECT * FROM STUDENT;
        ```
        

---

### Bullet Points:

#### Functions:

- Built-in and user-defined types.
    
- Return values; used in SQL queries.
    

#### Procedures:

- Encapsulate multiple SQL statements.
    
- Invoked using `CALL`.
    

#### Language Constructs:

- Include control statements (`IF`, `CASE`) and loops (`WHILE`).
    
- Cursors for row-wise processing.
