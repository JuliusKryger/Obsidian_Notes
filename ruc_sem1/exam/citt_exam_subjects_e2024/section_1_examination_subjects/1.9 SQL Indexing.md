### Reading Paper:

#### **What is SQL Indexing?**

SQL indexing involves creating a data structure that improves the speed of data retrieval operations on a table. Indexes are created on one or more columns to allow the database to locate data more efficiently, reducing the need to scan the entire table.

---

### Purpose of Indexing:

1. **Faster Query Execution:**
    
    - Reduces the amount of data the database needs to process for queries.
        
    - Example: Searching for specific rows in a table.
        
2. **Improved Sorting and Filtering:**
    
    - Indexes help optimize `ORDER BY` and `WHERE` clauses.
        
3. **Efficient Joins:**
    
    - Speed up operations involving multiple tables by indexing foreign keys.
        
4. **Enhanced Scalability:**
    
    - Supports large datasets with minimal performance degradation.
        

---

### How to Index a Table in SQL:

1. **Creating an Index:**
    
    - Use the `CREATE INDEX` statement to define an index.
        
    - **Syntax:**
        
        ```
        CREATE INDEX index_name
        ON table_name (column_name);
        ```
        
    - **Example:** Create an index on the `ROLL_NO` column of the `STUDENT` table.
        
        ```
        CREATE INDEX idx_roll_no
        ON STUDENT (ROLL_NO);
        ```
        
2. **Creating a Unique Index:**
    
    - Ensures all values in the indexed column are unique.
        
    - **Syntax:**
        
        ```
        CREATE UNIQUE INDEX index_name
        ON table_name (column_name);
        ```
        
    - **Example:**
        
        ```
        CREATE UNIQUE INDEX idx_email
        ON STUDENT (EMAIL);
        ```
        
3. **Composite Index:**
    
    - Indexes multiple columns.
        
    - **Syntax:**
        
        ```
        CREATE INDEX index_name
        ON table_name (column1, column2);
        ```
        
    - **Example:**
        
        ```
        CREATE INDEX idx_name_dob
        ON STUDENT (NAME, DOB);
        ```
        
4. **Dropping an Index:**
    
    - Use the `DROP INDEX` statement to remove an index.
        
    - **Syntax:**
        
        ```
        DROP INDEX index_name;
        ```

### How to Check Whether an Index is Used:

1. **Explain Query Plan:**
    
    - Use the `EXPLAIN` or `EXPLAIN PLAN` statement to analyze query execution.
        
    - **Syntax:**
        
        ```
        EXPLAIN SELECT column_name
        FROM table_name
        WHERE condition;
        ```
        
    - **Example:**
        
        ```
        EXPLAIN SELECT *
        FROM STUDENT
        WHERE ROLL_NO = 101;
        ```
        
    - **Result:** Look for index usage in the execution plan.
        
2. **Using Query Analyzer Tools:**
    
    - Most database systems provide tools (e.g., MySQL Workbench, PostgreSQL EXPLAIN ANALYZE) to check performance and index utilization.
        
3. **Monitoring Index Performance:**
    
    - Monitor query performance before and after index creation to verify its effectiveness.

### Bullet Points:

- **Purpose of Indexing:**
    
    - Speeds up data retrieval.
        
    - Optimizes sorting and filtering.
        
    - Enhances performance for large datasets.
        
- **Types of Indexes:**
    
    - Single-column, unique, and composite indexes.
        
- **Checking Index Usage:**
    
    - Use `EXPLAIN` to analyze query plans.
        
    - Compare performance metrics before and after indexing.
