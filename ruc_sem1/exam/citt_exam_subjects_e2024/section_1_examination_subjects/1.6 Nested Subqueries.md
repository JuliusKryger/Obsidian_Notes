### Reading Paper:

#### **What are Nested Subqueries?**

Nested subqueries are queries embedded within another SQL query. They are used to retrieve data that will be used in the main query, allowing for complex filtering and calculations.

---

### Types of Nested Subqueries:

#### **1. Subqueries Using** `**IN**` **and** `**EXISTS**`**:**

- `**IN**` **Subquery:**
    
    - Used to filter rows where a column's value matches any value returned by the subquery.
        
    - **Syntax:**
        
        ```
        SELECT column_name
        FROM table_name
        WHERE column_name IN (
          SELECT column_name
          FROM another_table
          WHERE condition
        );
        ```
        
    - **Example:** Retrieve students enrolled in courses offered by a specific instructor.
        
        ```
        SELECT NAME
        FROM STUDENT
        WHERE ROLL_NO IN (
          SELECT ROLL_NO
          FROM ENROLLMENT
          WHERE COURSE_ID IN (
            SELECT COURSE_ID
            FROM COURSE
            WHERE INSTRUCTOR = 'Dr. Smith'
          )
        );
        ```
        
- `**EXISTS**` **Subquery:**
    
    - Checks for the existence of rows returned by the subquery. Returns `TRUE` if the subquery returns any rows.
        
    - **Syntax:**
        
        ```
        SELECT column_name
        FROM table_name
        WHERE EXISTS (
          SELECT 1
          FROM another_table
          WHERE condition
        );
        ```
        
    - **Example:** Retrieve students who are enrolled in any course.
        
        ```
        SELECT NAME
        FROM STUDENT
        WHERE EXISTS (
          SELECT 1
          FROM ENROLLMENT
          WHERE STUDENT.ROLL_NO = ENROLLMENT.ROLL_NO
        );
        ```
        

---

#### **2. Subqueries Using** `**SOME**` **and** `**ALL**`**:**

- `**SOME**` **Subquery:**
    
    - Compares a value with any of the values returned by the subquery.
        
    - **Syntax:**
        
        ```
        SELECT column_name
        FROM table_name
        WHERE column_name > SOME (
          SELECT column_name
          FROM another_table
        );
        ```
        
    - **Example:** Retrieve students with grades higher than at least one other student in the same course.
        
- `**ALL**` **Subquery:**
    
    - Compares a value with all the values returned by the subquery.
        
    - **Syntax:**
        
        ```
        SELECT column_name
        FROM table_name
        WHERE column_name > ALL (
          SELECT column_name
          FROM another_table
        );
        ```
        
    - **Example:** Retrieve students with grades higher than all other students in their course.
        

---

#### **3. Subqueries in the** `**FROM**` **Clause:**

- Subqueries can be used as derived tables in the `FROM` clause, allowing them to act as temporary tables.
    
- **Syntax:**
    
    ```
    SELECT alias.column_name
    FROM (
      SELECT column_name
      FROM table_name
      WHERE condition
    ) AS alias
    WHERE condition;
    ```
    
- **Example:** Find the average grade of students by course using a subquery.
    
    ```
    SELECT COURSE_ID, AVG_GRADE
    FROM (
      SELECT COURSE_ID, AVG(GRADE) AS AVG_GRADE
      FROM GRADES
      GROUP BY COURSE_ID
    ) AS COURSE_AVG
    WHERE AVG_GRADE > 85;
    ```
    

---

### Bullet Points:

#### Subqueries Using `IN` and `EXISTS`:

- `IN`: Checks if a value exists in the result of a subquery.
    
- `EXISTS`: Returns `TRUE` if the subquery produces any rows.
    

#### Subqueries Using `SOME` and `ALL`:

- `SOME`: Compares a value with at least one value from the subquery.
    
- `ALL`: Compares a value with all values from the subquery.
    

#### Subqueries in `FROM` Clause:

- Subqueries can act as derived tables for temporary data processing.
