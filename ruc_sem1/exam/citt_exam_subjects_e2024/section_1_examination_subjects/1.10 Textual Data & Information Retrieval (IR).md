### Reading Paper:

#### **What is Information Retrieval (IR)?**

Information Retrieval (IR) is the process of obtaining relevant information from a large repository of textual data, such as documents or databases. IR systems aim to retrieve the most relevant documents based on a user query.

---

### Key Concepts:

#### **1. Keyword Search:**

- **Definition:**
    
    - A basic IR technique where the system matches user queries with keywords in documents.
        
- **Example:**
    
    - Query: "machine learning algorithms"
        
    - The system retrieves documents containing these words, ranking them based on occurrences.
        

#### **2. Inverted Index:**

- **Definition:**
    
    - A data structure used in IR systems to map keywords to their locations in a document collection.
        
    - Consists of:
        
        - **Term:** The keyword.
            
        - **Posting List:** List of documents containing the term, often with frequency and positions.
            
- **Steps to Build an Inverted Index:**
    
    1. Tokenize the text into words.
        
    2. Remove stopwords (e.g., "and," "the").
        
    3. Stem or lemmatize words to their root forms.
        
    4. Store terms with their corresponding document references.
        
- **Example:**
    
    ```
    Term       Posting List
    -----------------------
    "machine" [Doc1, Doc3]
    "learning" [Doc2, Doc3]
    "algorithm" [Doc1, Doc2]
    ```
    

#### **3. Relevance Ranking:**

- **Definition:**
    
    - Ranking documents based on their relevance to a query.
        
    - Common techniques:
        
        1. **Term Frequency-Inverse Document Frequency (TF-IDF):**
            
            - Measures how important a term is within a document and across the collection.
                
            - **Formula:**
                
                ```
                TF-IDF = TF(term) * log(N / DF(term))
                ```
                
                Where:
                
                - **TF(term):** Term frequency in the document.
                    
                - **DF(term):** Number of documents containing the term.
                    
                - **N:** Total number of documents.
                    
        2. **Cosine Similarity:**
            
            - Measures similarity between the query vector and document vectors.
                
            - **Formula:**
                
                ```
                Cosine Similarity = (A · B) / (||A|| ||B||)
                ```
                
                Where:
                
                - **A:** Query vector.
                    
                - **B:** Document vector.
                    
        3. **Language Models:**
            
            - Probabilistic models estimating query-document relevance based on likelihoods.
                

---

### Bullet Points:

- **Information Retrieval (IR):** Retrieves relevant textual data based on user queries.
    
- **Keyword Search:** Matches query terms to document terms.
    
- **Inverted Index:** Maps terms to their document occurrences for fast lookup.
    
- **Relevance Ranking:** Ranks documents using techniques like TF-IDF, Cosine Similarity, and Language Models.
