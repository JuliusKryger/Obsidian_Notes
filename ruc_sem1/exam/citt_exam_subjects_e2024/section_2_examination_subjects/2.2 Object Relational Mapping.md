#### **What is Object Relational Mapping (ORM)?**

Object Relational Mapping (ORM) is a technique for converting data between incompatible systems, specifically between object-oriented programming languages and relational databases. It automates the process of mapping classes to database tables, allowing developers to interact with the database using high-level programming constructs.

#### **Key Features of ORM:**

1. **Abstraction:**
    
    - Abstracts SQL queries by providing methods and classes for database operations.
        
2. **Automatic Mapping:**
    
    - Maps objects to database tables and properties to columns automatically.
        
3. **Improved Productivity:**
    
    - Reduces boilerplate code for database interactions.
        
4. **Portability:**
    
    - Facilitates switching between different databases with minimal changes.

### How to Handle Inheritance in ORM:

ORM frameworks provide multiple strategies for mapping inheritance hierarchies to database tables. Common approaches include:

1. **Table-per-Hierarchy (TPH):**
    
    - A single table stores data for the entire inheritance hierarchy.
        
    - **Advantages:**
        
        - Simplifies the schema.
            
        - Improves query performance.
            
    - **Disadvantages:**
        
        - Wasted space due to null values in columns.
            
    - **Example:**
        
        ```
        public class Employee
        {
            public int Id { get; set; }
            public string Name { get; set; }
        }
        
        public class Manager : Employee
        {
            public string Department { get; set; }
        }
        
        // Stored in a single table with columns: Id, Name, Department.
        ```
        
2. **Table-per-Type (TPT):**
    
    - Separate tables for each class in the hierarchy.
        
    - **Advantages:**
        
        - Normalized schema.
            
    - **Disadvantages:**
        
        - Joins required for queries.
            
    - **Example:**
        
        - `Employee` table with `Id` and `Name`.
            
        - `Manager` table with `Id` and `Department`.
            
3. **Table-per-Concrete-Class (TPC):**
    
    - Each class has its own table, including all inherited properties.
        
    - **Advantages:**
        
        - No joins required.
            
    - **Disadvantages:**
        
        - Data duplication.
            
    - **Example:**
        
        - Separate tables for `Employee` and `Manager` with repeated columns like `Name`.

### Entity Framework:

Entity Framework (EF) is a popular ORM framework for .NET applications. It simplifies data access by enabling developers to work with objects rather than database queries.

#### **Features of Entity Framework:**

1. **Code First:**
    
    - Define the database schema using C# classes and annotations.
        
    - **Example:**
        
        ```
        public class Student
        {
            public int Id { get; set; }
            public string Name { get; set; }
        }
        
        public class SchoolContext : DbContext
        {
            public DbSet<Student> Students { get; set; }
        }
        ```
        
2. **Database First:**
    
    - Generate C# classes from an existing database schema.
        
3. **Querying with LINQ:**
    
    - Allows complex queries using LINQ syntax.
        
    - **Example:**
        
        ```
        var students = context.Students
            .Where(s => s.Name.StartsWith("A"))
            .ToList();
        ```
        
4. **Change Tracking:**
    
    - Tracks object changes and generates appropriate SQL statements.
        
5. **Lazy and Eager Loading:**
    
    - Control when related data is loaded.

### Bullet Points:

- **ORM:** Automates the mapping of objects to database tables.
    
- **Inheritance Handling:**
    
    - Table-per-Hierarchy (TPH): Single table for the hierarchy.
        
    - Table-per-Type (TPT): Separate tables for each class.
        
    - Table-per-Concrete-Class (TPC): Separate tables for each class, including inherited properties.
        
- **Entity Framework:**
    
    - Features: Code First, Database First, LINQ support, change tracking, and data loading strategies.
