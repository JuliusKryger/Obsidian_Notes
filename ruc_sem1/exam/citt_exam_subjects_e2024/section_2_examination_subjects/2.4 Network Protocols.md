### Reading Paper:

#### **What is a Network Protocol?**

Network protocols are sets of rules that define how data is transmitted and received over a network. They ensure reliable communication between devices and systems, irrespective of their underlying architectures.

---

### OSI Model:

The OSI (Open Systems Interconnection) model provides a conceptual framework for understanding network interactions. It divides communication into seven layers:

1. **Physical Layer:**
    
    - Deals with hardware connections and the transmission of binary data.
        
    - Examples: Ethernet cables, USB.
        
2. **Data Link Layer:**
    
    - Handles error detection and correction in data frames.
        
    - Protocols: MAC (Media Access Control), ARP (Address Resolution Protocol).
        
3. **Network Layer:**
    
    - Responsible for logical addressing and routing.
        
    - Protocols: IP (Internet Protocol), ICMP (Internet Control Message Protocol).
        
4. **Transport Layer:**
    
    - Ensures reliable data transfer through error recovery and flow control.
        
    - Protocols: TCP (Transmission Control Protocol), UDP (User Datagram Protocol).
        
5. **Session Layer:**
    
    - Manages sessions and controls connections between applications.
        
6. **Presentation Layer:**
    
    - Handles data formatting, encryption, and compression.
        
    - Examples: SSL/TLS.
        
7. **Application Layer:**
    
    - Provides network services to end-users.
        
    - Protocols: HTTP, FTP, SMTP.

### Protocols:

#### **Common Network Protocols:**

1. **HTTP/HTTPS:**
    
    - Used for web communication.
        
    - HTTPS includes encryption for secure communication.
        
2. **FTP/SFTP:**
    
    - File Transfer Protocols for transferring files.
        
    - SFTP adds security.
        
3. **DNS (Domain Name System):**
    
    - Resolves domain names into IP addresses.
        
4. **SMTP/IMAP/POP3:**
    
    - Email protocols for sending and receiving messages.
        
5. **SNMP (Simple Network Management Protocol):**
    
    - Monitors and manages network devices.

### Routing and Switching:

#### **Routing:**

- Determines the best path for data to travel from source to destination.
    
- Devices: Routers.
    
- **Key Routing Protocols:**
    
    - **RIP (Routing Information Protocol):** Simple distance-vector protocol.
        
    - **OSPF (Open Shortest Path First):** Link-state protocol for scalable networks.
        
    - **BGP (Border Gateway Protocol):** Used for routing between ISPs.
        

#### **Switching:**

- Directs data packets within a local network.
    
- Devices: Switches.
    
- **Switching Techniques:**
    
    - **Circuit Switching:** Establishes a dedicated path for communication (e.g., telephone networks).
        
    - **Packet Switching:** Divides data into packets for efficient transmission (e.g., the internet).
        

---

### Bullet Points:

- **Network Protocols:** Define communication rules for data transmission.
    
- **OSI Model:** Seven-layer model for network interactions.
    
    - Key layers: Physical, Data Link, Network, Transport, Application.
        
- **Common Protocols:** HTTP, FTP, DNS, SMTP, SNMP.
    
- **Routing:** Determines data paths; key protocols include RIP, OSPF, BGP.
    
- **Switching:** Manages data within local networks; uses circuit or packet switching.
