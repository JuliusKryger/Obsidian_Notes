#### **What are Delegates in C#?**

A delegate in C# is a type that represents references to methods. It allows methods to be passed as parameters, enabling callback functionality and event-driven programming. Delegates are similar to function pointers in C++, but they are type-safe and secure.

#### **Key Features of Delegates:**

1. **Type Safety:**
    
    - Ensures the signature of the method matches the delegate type.
        
2. **Multicasting:**
    
    - A delegate can reference multiple methods, executed in the order they were added.
        
3. **Event Handling:**
    
    - Used extensively in event-driven programming to handle events.
        

#### **Syntax:**

```
// Delegate Declaration
public delegate void MyDelegate(string message);

// Method Matching Delegate Signature
public void PrintMessage(string msg)
{
    Console.WriteLine(msg);
}

// Usage
MyDelegate del = PrintMessage;
del("Hello, Delegates!");
```

#### **What are Lambda Expressions in C#?**

Lambda expressions are concise, anonymous functions that can be used wherever a delegate type is expected. They simplify the syntax for inline function definitions and are heavily used in LINQ and functional programming.

#### **Key Features of Lambda Expressions:**

1. **Conciseness:**
    
    - Reduces boilerplate code for defining small functions.
        
2. **Inline Functions:**
    
    - Can be used directly in method calls without separate declarations.
        
3. **Integration with LINQ:**
    
    - Lambda expressions are core to LINQ queries.
        

#### **Syntax:**

```
(parameters) => expression;

// Example:
Func<int, int> square = x => x * x;
Console.WriteLine(square(5)); // Output: 25

// Lambda with multiple parameters:
Func<int, int, int> add = (x, y) => x + y;
Console.WriteLine(add(3, 4)); // Output: 7
```

### Examples of Functional Programming in C#:

1. **Using Delegates:**
    
    ```
    public delegate int MathOperation(int x, int y);
    
    public class Program
    {
        public static int Add(int a, int b) => a + b;
        public static int Multiply(int a, int b) => a * b;
    
        public static void Main()
        {
            MathOperation op = Add;
            Console.WriteLine(op(3, 4)); // Output: 7
    
            op = Multiply;
            Console.WriteLine(op(3, 4)); // Output: 12
        }
    }
    ```
    
2. **Using Lambda Expressions with LINQ:**
    
    ```
    var numbers = new List<int> { 1, 2, 3, 4, 5 };
    
    // Filter using lambda
    var evenNumbers = numbers.Where(n => n % 2 == 0).ToList();
    Console.WriteLine(string.Join(", ", evenNumbers)); // Output: 2, 4
    ```
    
3. **Combining Delegates and Lambdas:**
    
    ```
    Func<int, int, int> calculate = (x, y) => x * y;
    Console.WriteLine(calculate(6, 7)); // Output: 42
    ```
