### Reading Paper:

#### **IP Protocol & IP Numbers:**

1. **IP Protocol (Internet Protocol):**
    
    - Handles addressing and routing of packets between devices on a network.
        
    - Divided into two versions:
        
        - **IPv4:**
            
            - 32-bit addresses, e.g., `192.168.1.1`.
                
            - Supports up to ~4.3 billion addresses.
                
        - **IPv6:**
            
            - 128-bit addresses, e.g., `2001:0db8:85a3:0000:0000:8a2e:0370:7334`.
                
            - Supports a vastly larger address space.
                
2. **IP Numbers:**
    
    - **Public IP:** Unique address for devices accessible over the internet.
        
    - **Private IP:** Used within local networks, not routable on the public internet (e.g., `192.168.x.x`, `10.x.x.x`).
        
    - **Dynamic vs. Static IP:**
        
        - **Dynamic:** Assigned by DHCP and may change.
            
        - **Static:** Manually configured and remains constant.

#### **TCP Connection Establishment:**

1. **Transmission Control Protocol (TCP):**
    
    - Ensures reliable communication between devices.
        
    - Provides features like error checking, sequencing, and retransmission.
        
2. **TCP Handshake Process:**
    
    - A three-step process for establishing a connection:
        
        1. **SYN (Synchronize):**
            
            - Client sends a SYN packet to initiate the connection.
                
        2. **SYN-ACK (Synchronize-Acknowledge):**
            
            - Server responds with a SYN-ACK packet to acknowledge the request.
                
        3. **ACK (Acknowledge):**
            
            - Client sends an ACK packet, completing the handshake.
                
    - Example:
        
        ```
        Client: SYN → Server
        Server: SYN-ACK → Client
        Client: ACK → Server
        Connection established.
        ```
        
3. **Closing a TCP Connection:**
    
    - Involves a four-step process using `FIN` and `ACK` packets.

#### **Application Layer:**

1. **Definition:**
    
    - The topmost layer in the OSI model, responsible for providing services to end-users.
        
    - Enables applications to communicate over a network.
        
2. **Common Protocols:**
    
    - **HTTP/HTTPS:** Used for web communication.
        
    - **FTP:** File Transfer Protocol for transferring files.
        
    - **SMTP/IMAP/POP3:** Email communication protocols.
        
    - **DNS:** Resolves domain names to IP addresses.
        
3. **Role in Network Communication:**
    
    - Facilitates user interaction with the network.
        
    - Relies on lower layers (e.g., transport and network) for data delivery.
        

---

### Bullet Points:

- **IP Protocol:** Handles addressing and routing (IPv4 and IPv6).
    
- **TCP Handshake:** Three steps (SYN, SYN-ACK, ACK) to establish connections.
    
- **Application Layer:** Provides end-user services (e.g., HTTP, DNS, SMTP).
