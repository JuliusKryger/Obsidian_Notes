### Reading Paper:

#### **What is ASP.NET?**

ASP.NET is a web development framework by Microsoft for building dynamic web applications, APIs, and services. It supports modern web standards and is part of the .NET ecosystem, enabling robust and scalable applications.

---

### MVC Architecture:

1. **Definition:**
    
    - MVC stands for Model-View-Controller, a design pattern for developing web applications.
        
2. **Components:**
    
    - **Model:**
        
        - Manages application data and business logic.
            
        - Communicates with the database.
            
    - **View:**
        
        - Responsible for the UI and presenting data to users.
            
    - **Controller:**
        
        - Handles user input and updates the Model and View accordingly.
            
3. **Workflow:**
    
    - User interacts with the View.
        
    - Controller processes input and interacts with the Model.
        
    - Model updates the data, and changes are reflected in the View.
        
4. **Advantages:**
    
    - Separation of concerns.
        
    - Easier testing and maintenance.
        
    - Scalability for complex applications.

### Middleware:

1. **Definition:**
    
    - Middleware are components in an ASP.NET application pipeline that handle requests and responses.
        
2. **Key Features:**
    
    - Execute sequentially for each HTTP request.
        
    - Add functionalities such as authentication, logging, and error handling.
        
3. **Examples of Middleware:**
    
    - **Authentication Middleware:** Verifies user credentials.
        
    - **Routing Middleware:** Directs requests to appropriate endpoints.
        
    - **Custom Middleware:** Allows developers to add application-specific logic.
        
4. **Creating Middleware:**
    
    ```
    public class CustomMiddleware
    {
        private readonly RequestDelegate _next;
    
        public CustomMiddleware(RequestDelegate next)
        {
            _next = next;
        }
    
        public async Task Invoke(HttpContext context)
        {
            // Custom logic before next middleware
            await context.Response.WriteAsync("Hello from Middleware!");
            await _next(context);
        }
    }
    ```
    
    - Register in `Startup.cs`:
        
        ```
        app.UseMiddleware<CustomMiddleware>();
        ```

### REST Services:

1. **Definition:**
    
    - ASP.NET provides tools for building RESTful APIs, enabling communication between systems.
        
2. **Key Features:**
    
    - Use of HTTP methods (`GET`, `POST`, `PUT`, `DELETE`).
        
    - JSON or XML response formats.
        
    - Routing via attribute-based or conventional methods.
        
3. **Example of a REST Controller:**
    
    ```
    [ApiController]
    [Route("api/[controller]")]
    public class ProductsController : ControllerBase
    {
        [HttpGet]
        public IActionResult GetAllProducts()
        {
            var products = new List<string> { "Product1", "Product2" };
            return Ok(products);
        }
    
        [HttpPost]
        public IActionResult AddProduct([FromBody] string product)
        {
            return Created($"api/products/{product}", product);
        }
    }
    ```
    
4. **Advantages:**
    
    - Easily integrates with client-side frameworks.
        
    - Scalable and lightweight for modern applications.

### Bullet Points:

- **MVC Architecture:** Separates application logic into Model, View, and Controller for better maintainability and testing.
    
- **Middleware:** Handles request-response pipelines with reusable components.
    
- **REST Services:** Simplifies API development with HTTP methods and JSON/XML support.
