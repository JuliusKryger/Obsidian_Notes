### Reading Paper:

#### **Numbers and Booleans:**

1. **Numbers:**
    
    - Represents integer and floating-point numbers.
        
    - **Special Values:**
        
        - `Infinity`, `-Infinity`, `NaN` (Not-a-Number).
            
    - **Methods:**
        
        - `toFixed(digits)`: Rounds a number to the specified decimal places.
            
        - `toString(base)`: Converts a number to a string in the specified base.
            
    - **Example:**
        
        ```
        let num = 123.456;
        console.log(num.toFixed(2)); // "123.46"
        console.log((255).toString(16)); // "ff"
        ```
        
2. **Booleans:**
    
    - Represents `true` or `false` values.
        
    - **Usage:**
        
        - Logical operations (`&&`, `||`, `!`). (AND, OR, NOT)
            
        - Conditional statements.
            
    - **Example:**
        
        ```
        let isStudent = true;
        console.log(isStudent && false); // false
        console.log(!isStudent); // false
        ```

#### **Arrays and Their Methods:**

1. **Definition:**
    
    - Ordered collections of values (can be of any type).
        
2. **Common Methods:**
    
    - **Manipulation:**
        
        - `push(value)`: Adds value to the end of the array.
            
        - `pop()`: Removes the last value.
            
        - `shift()`: Removes the first value.
            
        - `unshift(value)`: Adds value to the beginning.
            
    - **Iteration:**
        
        - `forEach(callback)`: Executes a callback for each element.
            
        - `map(callback)`: Creates a new array by applying a function to each element.
            
    - **Filtering and Searching:**
        
        - `filter(callback)`: Returns elements that satisfy the condition.
            
        - `find(callback)`: Finds the first element satisfying the condition.
            
    - **Sorting and Reducing:**
        
        - `sort()`: Sorts the array.
            
        - `reduce(callback, initialValue)`: Reduces the array to a single value.
            
    - **Example:**
        
        ```
        let numbers = [1, 2, 3, 4];
        let squares = numbers.map(num => num ** 2);
        console.log(squares); // [1, 4, 9, 16]
        
        let evenNumbers = numbers.filter(num => num % 2 === 0);
        console.log(evenNumbers); // [2, 4]
        ```

#### **Strings and Their Methods:**

1. **Definition:**
    
    - Immutable sequences of characters.
        
2. **Common Methods:**
    
    - **Manipulation:**
        
        - `toUpperCase()`: Converts to uppercase.
            
        - `toLowerCase()`: Converts to lowercase.
            
        - `trim()`: Removes whitespace from both ends.
            
    - **Searching:**
        
        - `indexOf(substring)`: Returns the index of the first occurrence of a substring.
            
        - `includes(substring)`: Checks if the string contains the substring.
            
    - **Splitting and Joining:**
        
        - `split(delimiter)`: Splits a string into an array.
            
        - `join(delimiter)`: Joins an array into a string.
            
    - **Example:**
        
        ```
        let str = " Hello, World! ";
        console.log(str.trim().toUpperCase()); // "HELLO, WORLD!"
        
        let words = "apple,banana,cherry".split(",");
        console.log(words); // ["apple", "banana", "cherry"]
        ```
        

---

### Bullet Points:

- **Numbers:** Support special values like `Infinity` and `NaN`. Common methods: `toFixed()`, `toString()`.
    
- **Booleans:** Represent `true` or `false`. Used in logical operations and conditionals.
    
- **Arrays:** Ordered collections with methods like `push()`, `map()`, `filter()`.
    
- **Strings:** Immutable character sequences with methods like `trim()`, `split()`, `includes()`.
