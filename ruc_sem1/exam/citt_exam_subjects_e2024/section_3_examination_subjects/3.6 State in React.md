### Reading Paper:

#### **Stateful Components:**

1. **Definition:**
    
    - Components that manage and maintain their own state.
        
    - State represents dynamic data that changes over time, triggering re-renders.
        
2. **Class Components:**
    
    - State is managed using `this.state` and updated using `this.setState()`.
        
    - **Example:**
        
        ```
        class Counter extends React.Component {
            constructor(props) {
                super(props);
                this.state = { count: 0 };
            }
        
            increment = () => {
                this.setState({ count: this.state.count + 1 });
            };
        
            render() {
                return (
                    <div>
                        <p>Count: {this.state.count}</p>
                        <button onClick={this.increment}>Increment</button>
                    </div>
                );
            }
        }
        ```
        
3. **Functional Components:**
    
    - State is managed using the `useState` hook.
        

---

#### **useState: Initializing, Getting, and Setting:**

1. **Initializing State:**
    
    - Use the `useState` hook to declare state variables.
        
    - **Syntax:**
        
        ```
        const [state, setState] = useState(initialValue);
        ```
        
    - **Example:**
        
        ```
        const [count, setCount] = useState(0);
        ```
        
2. **Getting State:**
    
    - Access the current state value directly using the state variable.
        
    - **Example:**
        
        ```
        console.log(count); // Access current state value
        ```
        
3. **Setting State:**
    
    - Update state using the setter function provided by `useState`.
        
    - **Example:**
        
        ```
        const increment = () => setCount(count + 1);
        ```
        
4. **Functional Updates:**
    
    - Use a function to update state based on the previous value.
        
    - **Example:**
        
        ```
        setCount(prevCount => prevCount + 1);
        ```
        

---

#### **State in the Component Hierarchy:**

1. **Lifting State Up:**
    
    - Move state to a common ancestor component when multiple components need access to the same state.
        
    - **Example:**
        
        ```
        function Parent() {
            const [sharedState, setSharedState] = useState("Shared data");
        
            return (
                <div>
                    <Child1 state={sharedState} />
                    <Child2 updateState={setSharedState} />
                </div>
            );
        }
        ```
        
2. **Prop Drilling:**
    
    - Passing state and setter functions down through the component tree.
        
    - Use tools like Context API to avoid deep prop drilling.
        
3. **State Management Libraries:**
    
    - For complex applications, use libraries like Redux, MobX, or Zustand to manage state globally.
        

---

### Bullet Points:

- **Stateful Components:** Manage and update state internally.
    
- **useState Hook:**
    
    - Initialize: `const [state, setState] = useState(initialValue)`.
        
    - Get: Access directly using the state variable.
        
    - Set: Use the setter function or functional updates.
        
- **State Hierarchy:**
    
    - Lift state up for shared access.
        
    - Use Context API or state management libraries for scalability.
