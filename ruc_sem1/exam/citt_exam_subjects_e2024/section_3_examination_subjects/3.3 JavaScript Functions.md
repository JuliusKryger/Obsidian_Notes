### Reading Paper:

#### **Declaring Functions:**

1. **Function Declarations:**
    
    - Define a named function that can be invoked anywhere in its scope.
        
    - **Syntax:**
        
        ```
        function functionName(parameters) {
            // Function body
            return value;
        }
        ```
        
    - **Example:**
        
        ```
        function greet(name) {
            return `Hello, ${name}`;
        }
        console.log(greet("Alice")); // "Hello, Alice"
        ```
        
2. **Arrow Functions:**
    
    - Concise syntax for writing functions.
        
    - **Syntax:**
        
        ```
        (parameters) => expression;
        ```
        
    - **Example:**
        
        ```
        const add = (a, b) => a + b;
        console.log(add(3, 5)); // 8
        ```
        

---

#### **Function Expressions; Functions as Values; Event Handlers:**

1. **Function Expressions:**
    
    - Assign a function to a variable.
        
    - **Syntax:**
        
        ```
        const variableName = function(parameters) {
            // Function body
        };
        ```
        
    - **Example:**
        
        ```
        const square = function(num) {
            return num * num;
        };
        console.log(square(4)); // 16
        ```
        
2. **Functions as Values:**
    
    - Functions can be assigned to variables, passed as arguments, or returned by other functions.
        
    - **Example:**
        
        ```
        const logger = console.log;
        logger("Functions are values too!");
        ```
        
3. **Event Handlers:**
    
    - Functions that respond to events (e.g., clicks, input changes).
        
    - **Example:**
        
        ```
        document.getElementById("btn").addEventListener("click", function() {
            alert("Button clicked!");
        });
        ```
        

---

#### **Functions as Input or Output:**

1. **Higher-Order Functions:**
    
    - Accept other functions as arguments or return them as results.
        
    - **Example:**
        
        ```
        function processArray(arr, callback) {
            return arr.map(callback);
        }
        const result = processArray([1, 2, 3], num => num * 2);
        console.log(result); // [2, 4, 6]
        ```
        
2. **Returning Functions:**
    
    - A function can return another function.
        
    - **Example:**
        
        ```
        function createMultiplier(factor) {
            return function(num) {
                return num * factor;
            };
        }
        const double = createMultiplier(2);
        console.log(double(5)); // 10
        ```
        

---

### Bullet Points:

- **Function Declarations:** Named functions defined using the `function` keyword.
    
- **Function Expressions:** Functions assigned to variables.
    
- **Arrow Functions:** Concise syntax for inline functions.
    
- **Event Handlers:** Functions that respond to events like clicks or input.
    
- **Higher-Order Functions:** Accept functions as arguments or return them as outputs.
