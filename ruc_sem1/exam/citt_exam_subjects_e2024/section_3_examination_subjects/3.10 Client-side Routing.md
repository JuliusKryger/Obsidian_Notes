### Reading Paper:

#### **Simple Routes; Nested Routes:**

1. **Simple Routes:**
    
    - Define paths in a single-page application (SPA) to display specific components.
        
    - Use React Router's `<Route>` component to map paths to components.
        
    - **Example:**
        
        ```
        import { BrowserRouter as Router, Routes, Route } from "react-router-dom";
        
        function App() {
            return (
                <Router>
                    <Routes>
                        <Route path="/" element={<Home />} />
                        <Route path="/about" element={<About />} />
                    </Routes>
                </Router>
            );
        }
        ```
        
2. **Nested Routes:**
    
    - Allow for hierarchical routing where child routes are rendered within parent routes.
        
    - **Example:**
        
        ```
        function Dashboard() {
            return (
                <Routes>
                    <Route path="/" element={<Overview />} />
                    <Route path="/settings" element={<Settings />} />
                </Routes>
            );
        }
        ```

#### **Route Parameters:**

1. **Definition:**
    
    - Dynamically match parts of the URL and pass them as props to components.
        
2. **Syntax:**
    
    - Define parameters with a colon prefix (`:`).
        
    - Access them using `useParams()` from React Router.
        
3. **Example:**
    
    ```
    import { useParams } from "react-router-dom";
    
    function UserProfile() {
        const { userId } = useParams();
        return <h1>Profile of User: {userId}</h1>;
    }
    
    function App() {
        return (
            <Routes>
                <Route path="/user/:userId" element={<UserProfile />} />
            </Routes>
        );
    }
    ```

#### **Links:**

1. **Definition:**
    
    - Use `<Link>` or `<NavLink>` components from React Router to navigate between routes without reloading the page.
        
2. `**<Link>**` **Example:**
    
    ```
    import { Link } from "react-router-dom";
    
    function Navbar() {
        return (
            <nav>
                <Link to="/">Home</Link>
                <Link to="/about">About</Link>
            </nav>
        );
    }
    ```
    
3. `**<NavLink>**` **Example:**
    
    - Highlights the active link.
        
    - **Example:**
        
        ```
        import { NavLink } from "react-router-dom";
        
        function Navbar() {
            return (
                <nav>
                    <NavLink to="/" activeClassName="active">Home</NavLink>
                    <NavLink to="/about" activeClassName="active">About</NavLink>
                </nav>
            );
        }
        ```
        

---

### Bullet Points:

- **Simple Routes:** Map paths to components using `<Route>`.
    
- **Nested Routes:** Define child routes rendered within parent components.
    
- **Route Parameters:** Match dynamic segments in URLs; access using `useParams()`.
    
- **Links:**
    
    - Use `<Link>` for navigation without page reloads.
        
    - Use `<NavLink>` for active link styling.
