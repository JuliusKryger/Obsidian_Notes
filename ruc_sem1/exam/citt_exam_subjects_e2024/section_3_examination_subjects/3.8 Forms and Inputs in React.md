### Reading Paper:

#### **Controlled and Uncontrolled Components:**

1. **Controlled Components:**
    
    - Input elements whose values are controlled by React state.
        
    - Changes are managed through `onChange` handlers.
        
    - **Example:**
        
        ```
        function ControlledInput() {
            const [value, setValue] = useState("");
        
            const handleChange = (event) => {
                setValue(event.target.value);
            };
        
            return (
                <input type="text" value={value} onChange={handleChange} />
            );
        }
        ```
        
2. **Uncontrolled Components:**
    
    - Input elements that manage their own state.
        
    - Access the current value using a `ref`.
        
    - **Example:**
        
        ```
        function UncontrolledInput() {
            const inputRef = useRef();
        
            const handleSubmit = () => {
                alert(inputRef.current.value);
            };
        
            return (
                <>
                    <input type="text" ref={inputRef} />
                    <button onClick={handleSubmit}>Submit</button>
                </>
            );
        }
        ```

#### **Filtering, Masking, and Validating Text Inputs:**

1. **Filtering Input:**
    
    - Prevent unwanted characters or patterns in input fields.
        
    - **Example:** Allow only numbers:
        
        ```
        const handleChange = (event) => {
            const value = event.target.value.replace(/\D/g, "");
            setValue(value);
        };
        ```
        
2. **Masking Input:**
    
    - Format input as the user types (e.g., phone numbers, dates).
        
    - Use libraries like `react-input-mask` for complex cases.
        
    - **Example:**
        
        ```
        import InputMask from "react-input-mask";
        
        function MaskedInput() {
            return <InputMask mask="(999) 999-9999" placeholder="Phone number" />;
        }
        ```
        
3. **Validating Input:**
    
    - Ensure input meets certain criteria.
        
    - **Example:** Email validation:
        
        ```
        const validateEmail = (email) => {
            const regex = /^[\w-\.]+@[\w-]+\.[a-z]{2,}$/i;
            return regex.test(email);
        };
        
        const handleChange = (event) => {
            const email = event.target.value;
            setIsValid(validateEmail(email));
        };
        ```

#### **Sharing Event Handlers; Event Objects:**

1. **Sharing Event Handlers:**
    
    - Use a single handler for multiple inputs by leveraging the `name` attribute.
        
    - **Example:**
        
        ```
        const handleInputChange = (event) => {
            const { name, value } = event.target;
            setFormData((prev) => ({ ...prev, [name]: value }));
        };
        
        return (
            <>
                <input name="firstName" onChange={handleInputChange} />
                <input name="lastName" onChange={handleInputChange} />
            </>
        );
        ```
        
2. **Event Objects:**
    
    - Event handlers in React receive an `event` object containing details about the event.
        
    - **Properties:**
        
        - `event.target`: The element that triggered the event.
            
        - `event.preventDefault()`: Prevents the default action.
            
        - `event.stopPropagation()`: Stops event bubbling.
            
    - **Example:**
        
        ```
        const handleSubmit = (event) => {
            event.preventDefault();
            console.log("Form submitted");
        };
        
        return <form onSubmit={handleSubmit}>...</form>;
        ```
        

---

### Bullet Points:

- **Controlled Components:** Inputs managed via React state with `onChange` handlers.
    
- **Uncontrolled Components:** Inputs manage their own state, accessed using `ref`.
    
- **Filtering Input:** Removes unwanted characters or patterns (e.g., only numbers).
    
- **Masking Input:** Formats input dynamically (e.g., phone numbers).
    
- **Validating Input:** Ensures input meets criteria (e.g., email regex).
    
- **Event Handlers:**
    
    - Share handlers for multiple inputs using `name` attributes.
        
    - Use `event` objects for input details and controlling behavior.
