### Reading Paper:

#### **Rules of Hooks:**

1. **Call Hooks at the Top Level:**
    
    - Hooks must not be called inside loops, conditions, or nested functions.
        
    - Ensures that hooks are always called in the same order during every render.
        
2. **Only Call Hooks from React Functions:**
    
    - Hooks can only be called inside functional components or custom hooks.
        
    - **Invalid Example:**
        
        ```
        if (condition) {
            const [state, setState] = useState(0); // Invalid
        }
        ```
        
3. **Custom Hooks:**
    
    - Reusable logic can be encapsulated in custom hooks.
        
    - **Example:**
        
        ```
        function useCustomHook() {
            const [value, setValue] = useState(0);
            return [value, setValue];
        }
        ```

#### **useEffect:**

1. **Definition:**
    
    - The `useEffect` hook lets you perform side effects (e.g., data fetching, subscriptions) in function components.
        
2. **Syntax:**
    
    ```
    useEffect(() => {
        // Effect logic
        return () => {
            // Cleanup logic (optional)
        };
    }, [dependencies]);
    ```
    
3. **Common Use Cases:**
    
    - **Data Fetching:**
        
        ```
        useEffect(() => {
            fetch("https://api.example.com/data")
                .then(response => response.json())
                .then(data => console.log(data));
        }, []); // Empty dependency array runs effect once
        ```
        
    - **Subscriptions:**
        
        ```
        useEffect(() => {
            const id = setInterval(() => console.log("Tick"), 1000);
            return () => clearInterval(id); // Cleanup interval
        }, []);
        ```
        
    - **Reacting to Props or State Changes:**
        
        ```
        useEffect(() => {
            console.log("State changed");
        }, [state]); // Runs when `state` changes
        ```
        
4. **Cleanup:**
    
    - Cleanup functions run before the component unmounts or before re-running the effect.

#### **useContext:**

1. **Definition:**
    
    - The `useContext` hook allows components to access values from a React context without passing props explicitly.
        
2. **Steps to Use useContext:**
    
    - **Create Context:**
        
        ```
        const MyContext = React.createContext(defaultValue);
        ```
        
    - **Provide Context Value:**
        
        ```
        <MyContext.Provider value={sharedValue}>
            <ChildComponent />
        </MyContext.Provider>
        ```
        
    - **Consume Context Value:**
        
        ```
        const value = useContext(MyContext);
        console.log(value);
        ```
        
3. **Example:**
    
    ```
    const ThemeContext = React.createContext("light");
    
    function ThemeComponent() {
        const theme = useContext(ThemeContext);
        return <div className={theme}>Current theme: {theme}</div>;
    }
    
    function App() {
        return (
            <ThemeContext.Provider value="dark">
                <ThemeComponent />
            </ThemeContext.Provider>
        );
    }
    ```
    

---

### Bullet Points:

- **Rules of Hooks:**
    
    - Call hooks at the top level, only in React functions.
        
    - Use custom hooks to encapsulate reusable logic.
        
- **useEffect:**
    
    - Perform side effects like fetching data or setting up subscriptions.
        
    - Cleanup logic runs before unmounting or re-running effects.
        
- **useContext:**
    
    - Access context values without prop drilling.
        
    - Requires a context provider and consumer setup.
