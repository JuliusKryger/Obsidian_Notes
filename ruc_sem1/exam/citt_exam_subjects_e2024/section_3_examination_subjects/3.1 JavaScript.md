### Reading Paper:

#### **Variables, Values, and Types:**

1. **Variables:**
    
    - Declared using `var`, `let`, or `const`.
        
        - `var`: Function-scoped, allows redeclaration.
            
        - `let`: Block-scoped, cannot be redeclared.
            
        - `const`: Block-scoped, immutable (value cannot be reassigned).
            
2. **Values and Types:**
    
    - **Primitive Types:**
        
        - Examples: `string`, `number`, `boolean`, `null`, `undefined`, `bigint`, `symbol`.
            
    - **Non-Primitive Types:**
        
        - Objects (arrays, functions, etc.).
            
    - **Dynamic Typing:**
        
        - Variables can hold values of any type.
            
3. **Example:**
    
    ```
    let name = "John"; // string
    const age = 25; // number
    let isStudent = true; // boolean
    let address = null; // null
    let grade; // undefined
    ```
    

---

#### **Functions:**

1. **Function Declarations:**
    
    - Traditional way to define a function.
        
    - Example:
        
        ```
        function greet(name) {
          return `Hello, ${name}`;
        }
        console.log(greet("Alice"));
        ```
        
2. **Function Expressions:**
    
    - Functions assigned to variables.
        
    - Example:
        
        ```
        const add = function(a, b) {
          return a + b;
        };
        console.log(add(2, 3));
        ```
        
3. **Arrow Functions:**
    
    - Concise syntax for function expressions.
        
    - Example:
        
        ```
        const multiply = (a, b) => a * b;
        console.log(multiply(4, 5));
        ```
        
4. **Higher-Order Functions:**
    
    - Functions that take other functions as arguments or return them.
        
    - Example:
        
        ```
        const numbers = [1, 2, 3, 4];
        const squares = numbers.map(num => num * num);
        console.log(squares);
        ```
        

---

#### **Arrays and Objects:**

1. **Arrays:**
    
    - Ordered collections of elements.
        
    - **Methods:**
        
        - `push()`, `pop()`, `map()`, `filter()`, `reduce()`, `forEach()`, etc.
            
    - Example:
        
        ```
        const fruits = ["apple", "banana", "cherry"];
        fruits.push("date");
        console.log(fruits);
        ```
        
2. **Objects:**
    
    - Key-value pairs for representing structured data.
        
    - **Accessing Properties:**
        
        - Dot notation: `obj.key`
            
        - Bracket notation: `obj["key"]`
            
    - Example:
        
        ```
        const person = {
          name: "John",
          age: 30,
          greet() {
            return `Hi, I'm ${this.name}`;
          }
        };
        console.log(person.greet());
        ```
        

---

### Bullet Points:

- **Variables:** Declared using `var`, `let`, or `const`.
    
- **Values and Types:**
    
    - Primitive types: `string`, `number`, `boolean`, etc.
        
    - Non-primitive types: Objects (arrays, functions).
        
- **Functions:**
    
    - Types: Declarations, expressions, arrow functions.
        
    - Higher-order functions: Use with methods like `map()`.
        
- **Arrays:** Ordered collections with methods like `push()`, `map()`, and `filter()`.
    
- **Objects:** Key-value pairs with properties and methods.
