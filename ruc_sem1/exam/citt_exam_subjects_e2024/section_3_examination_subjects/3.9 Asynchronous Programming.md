### Reading Paper:

#### **fetch; Threads:**

1. **fetch API:**
    
    - A modern interface for making HTTP requests in JavaScript.
        
    - **Syntax:**
        
        ```
        fetch(url, options)
            .then(response => response.json())
            .then(data => console.log(data))
            .catch(error => console.error("Error:", error));
        ```
        
    - **Example:**
        
        ```
        fetch("https://api.example.com/data")
            .then(response => {
                if (!response.ok) {
                    throw new Error("Network response was not ok");
                }
                return response.json();
            })
            .then(data => console.log(data))
            .catch(error => console.error("Fetch error:", error));
        ```
        
2. **Threads:**
    
    - JavaScript is single-threaded but supports asynchronous operations through the event loop and Web APIs.
        
    - **Web Workers:** Enable multithreading for complex computations.
        
        - **Example:**
            
            ```
            const worker = new Worker("worker.js");
            worker.postMessage("Start");
            worker.onmessage = (event) => {
                console.log("Message from worker:", event.data);
            };
            ```

#### **Promises; Callbacks; async/await:**

1. **Promises:**
    
    - Represent a value that will be resolved in the future.
        
    - **States:** Pending, Fulfilled, Rejected.
        
    - **Example:**
        
        ```
        const promise = new Promise((resolve, reject) => {
            setTimeout(() => resolve("Success!"), 1000);
        });
        
        promise.then(result => console.log(result)).catch(error => console.error(error));
        ```
        
2. **Callbacks:**
    
    - Functions passed as arguments to other functions, executed after an asynchronous operation.
        
    - **Example:**
        
        ```
        function fetchData(callback) {
            setTimeout(() => {
                callback("Data fetched");
            }, 1000);
        }
        
        fetchData((message) => console.log(message));
        ```
        
3. **async/await:**
    
    - Syntactic sugar over promises for writing asynchronous code in a synchronous manner.
        
    - **Example:**
        
        ```
        async function fetchData() {
            try {
                const response = await fetch("https://api.example.com/data");
                const data = await response.json();
                console.log(data);
            } catch (error) {
                console.error("Error:", error);
            }
        }
        
        fetchData();
        ```

#### **Handling Errors:**

1. **Using try...catch:**
    
    - Handle errors in `async/await` code blocks.
        
    - **Example:**
        
        ```
        async function fetchData() {
            try {
                const response = await fetch("https://api.example.com/data");
                if (!response.ok) {
                    throw new Error("HTTP error! Status: " + response.status);
                }
                const data = await response.json();
                console.log(data);
            } catch (error) {
                console.error("Fetch error:", error);
            }
        }
        ```
        
2. **catch() with Promises:**
    
    - Catch errors in promise chains.
        
    - **Example:**
        
        ```
        fetch("https://api.example.com/data")
            .then(response => response.json())
            .then(data => console.log(data))
            .catch(error => console.error("Error:", error));
        ```
        
3. **Event Listeners for Errors:**
    
    - Handle global errors using event listeners.
        
    - **Example:**
        
        ```
        window.addEventListener("error", (event) => {
            console.error("Global error:", event.message);
        });
        
        window.addEventListener("unhandledrejection", (event) => {
            console.error("Unhandled promise rejection:", event.reason);
        });
        ```
        

---

### Bullet Points:

- **fetch API:** Modern interface for HTTP requests with `.then()` and `.catch()` chaining.
    
- **Threads:** JavaScript uses single-threaded event loop; Web Workers enable multithreading.
    
- **Promises:** Represent future values; use `.then()` and `.catch()` for handling.
    
- **Callbacks:** Functions executed after async operations; prone to callback hell.
    
- **async/await:** Cleaner syntax for asynchronous code, using `try...catch` for error handling.
    
- **Error Handling:**
    
    - Use `try...catch` in `async/await`.
        
    - Use `.catch()` with promises.
        
    - Add global error listeners for comprehensive error management.
